# Chrome Web Store listing draft

**Name:** AskJev  
**Short:** Jev autopilot for any site — with a guard on irreversible clicks.  
**Category:** Productivity  

**Description:**
AskJev turns TypeSafe’s Jev (System One) into a browser autopilot and a safety brake.

**Autopilot** — open the side panel, type a goal, and Jev picks the next click, type, or scroll from the live page. AskJev executes it. Works on every website.

**Guard** — when you hit Pay, Delete, Send, Approve, Deploy, and similar high-impact controls, AskJev freezes the click and asks Jev: is this irreversible, how risky is it, and should we proceed, block, or ask you? Autopilot also stops if the next step looks irreversible.

Not Claude. Not a chat agent. Fast structured decisions from TypeSafe Jev only. Your API key stays in Chrome storage and is sent only to api.typesafe.ai. No AskJev servers.

**Privacy:** Key in Chrome sync. Context only to api.typesafe.ai. No AskJev backend.
