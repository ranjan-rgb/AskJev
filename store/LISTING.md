# Chrome Web Store listing draft

**Name:** Holdfire  
**Short:** Jev holds fire on pay, delete, and send before the click lands.  
**Category:** Productivity / Accessibility  

**Description:**
Holdfire uses TypeSafe’s Jev (a System One decision model) to pause dangerous browser clicks. When you hit Pay, Delete, Send, Approve, or Deploy, Holdfire asks Jev whether the click is irreversible, how risky it is, and whether to proceed, block, or ask you. Not a browser-driving agent — a safety brake.

**Privacy:** Key in Chrome storage. Context only to api.typesafe.ai. No Holdfire servers.
