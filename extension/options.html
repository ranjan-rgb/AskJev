Connect Claude / Cursor

Claude starts the bridge for you. There is no URL to paste. Auto-connect writes a config so Claude Desktop (or Cursor) launches npx -y askjev-mcp over stdio. The only network path is local ws://127.0.0.1:PORT between askjev-mcp and this extension — automatic, localhost only.

  1. Click Auto-connect (creates a pairing token + arms the bridge).
  2. Copy config or download an installer (writes Claude’s config file for you).
  3. Restart Claude Desktop / Cursor → extension status shows paired.
